Mask shapes.

A team is a grid: six candidates down, eight fields across. To make a new team you hide some cells and ask the model to fill them back in. Which cells you hide is the mask shape, and it decided almost everything — the same weights go from unusable to near-perfect depending on the pattern alone.

The forward process — masking accumulates

Time runs 0 to 1. At time t each cell is masked with probability t, and masking is absorbing: once a cell is hidden it stays hidden. So the sheet fills up until nothing is left. Sampling runs this backwards — start all green, unmask a fraction each step until the sheet is complete.

forward → mask more (this is the corruption, not something the model does) ← reverse unmask a fraction each step (this is generation)

Training never walks this strip. Each step draws one random t and jumps straight to that frame — outlined above — because “each cell masked with probability t” has a closed form and can be sampled in one shot. Walking the intermediate steps would cost far more and produce the same distribution. Over many steps the model sees every frame, just never in order.
